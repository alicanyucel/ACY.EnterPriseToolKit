# EnterpriseToolkit

**EnterpriseToolkit** is a .NET 10 Class Library designed to solve common enterprise challenges in one unified package:

- 🔄 Cache Consistency (Redis + MemoryCache synchronization, automatic invalidation)
- 🛡️ Resilience (Retry, exponential backoff, circuit breaker)
- 📊 Job Monitoring (Job logging and tracking)
- 📝 Audit & Change Tracking (Automatic entity change logging)

---

## 🚀 Installation

```bash
dotnet add package EnterpriseToolkit
